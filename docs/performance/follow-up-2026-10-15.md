# Perbaikan PageSpeed mobile 2026-10-15

Branch: `bugfix/fix-pagespeed`. Pengguna menyetujui perubahan dan pesan commit pada 2026-10-15 sebelum publikasi.

## Penyebab dan perubahan

[Laporan Google PageSpeed pengguna](https://pagespeed.web.dev/analysis/https-farhanreninda-my-id/pxdutcna4k?hl=id&form_factor=mobile) mencatat mobile 98, FCP 1,2 detik, LCP 1,4 detik, TBT 0, CLS 0, dan Speed Index 4,2 detik. Audit juga menunjukkan stylesheet awal memblokir render. Audit CLI terhadap produksi saat pemeriksaan mendapat 99, sehingga angka antar-pengukuran memang bervariasi.

Build kini menyisipkan stylesheet entry yang kecil langsung ke HTML dan menghapus link stylesheet tersebut. HTML gzip bertambah dari 0,99 KB menjadi 6,30 KB, tetapi browser melewati satu permintaan jaringan sebelum render. CSS halaman HomeView tetap berupa berkas terpisah dengan preload; tidak menyisipkan seluruh CSS halaman atau CSS admin. Tema awal, metadata charset, URL font, data CMS, dan desain dipertahankan.

Hasil tambahan tetap disimpan di JSON; hubungan dengan beban mesin adalah indikasi dari benchmark, bukan jaminan penyebab tunggal atau jaminan semua run akan 100.

- Build/type-check PASS: `npm run build`.
- Regresi PASS: `npm test`, 9 tes; tes baru menjalankan hook build dan memastikan CSS entry saja disisipkan, preload route tetap ada, serta script tema dan metadata tidak dihapus.

- Layout PASS: Natural 390px ID/EN dan light/dark, admin 320px, Original 1280px; tidak ada overflow horizontal.
- Interaksi PASS: menu membuka lalu menutup saat memilih Proyek; dialog SIP 13 gambar terbuka, Escape menutup dan fokus kembali ke kartu. Bahasa dan mode mengganti konten/palet. Original menampilkan tujuh section; gerbang admin tetap tersedia. Tidak ada error/warning console.
